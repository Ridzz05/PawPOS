# Design Rationale

This project adheres to the **Stripe Design System** specification defined in [DESIGN.md](file:///c:/Users/muhri/Documents/ai-operational-pos/DESIGN.md) (sourced from `docs/awesome-design-md/design-md/stripe/DESIGN.md`).

## Core Visual Language:
1. **Primary & Brand Accent**: Electric Indigo (`#533afd`, press `#2e2b8c`, hover `#4434d4`).
2. **Surfaces & Layout**:
   - Page background: `#f6f9fc` (crisp off-white canvas).
   - Surfaces & Paper: `#ffffff` with hairline borders `#e3e8ee` and subtle elevation (`rgba(50, 50, 93, 0.05)`).
   - Persistent desktop rail and compact mobile navigation.
3. **Typography**:
   - Modern clean sans-serif (`Segoe UI`, `SF Pro Display`, `system-ui`).
   - High-density tabular numerals (`tnum`) for monetary values, prices, inventory counters, and SKUs.
4. **Interactive Controls**:
   - Buttons: Pill/semi-rounded (`borderRadius: 8px`), crisp states, clear focus outline (`#533afd`).
   - Status indicators: Stripe Emerald (`#00875a`), Amber (`#e27e00`), and Ruby (`#df1b41`).
